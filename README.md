# 三角洲行动活动复刻页（非官方）

> 仿照《三角洲行动》游戏内活动制作的单文件网页。非官方粉丝作品，与腾讯公司及《三角洲行动》官方无关。

- 在线预览：https://haavkwebsite.rth1.xyz
- 仓库地址：https://github.com/BMgzs/delta-event-fanpage

## 项目简介

这是一个仿照《三角洲行动》游戏内活动页面制作的静态网页项目。项目只有一个 `index.html`，不依赖构建工具，双击即可打开；图片、音乐等素材通过直连、图床或内嵌 SVG 使用，`file://` 协议打开与在线托管效果基本一致。

本项目仅用于学习、交流、非商业展示和游戏资料参考。

## 项目结构

```text
.
├── index.html
├── README.md
└── LICENSE
```

## 特性

- **单文件**：整个项目只有一个 `index.html`。
- **零构建**：无需 npm、无需打包、无需后端。
- **双击即用**：直接打开 `index.html` 即可浏览。
- **素材方式**：图片/音乐使用外链直连、图床；部分图标为内嵌 SVG。
- **静态部署**：可部署到热铁盒、GitHub Pages、Netlify、Vercel 等任意静态托管。
- **在线预览**：https://haavkwebsite.rth1.xyz

## 本地运行

```bash
git clone https://github.com/BMgzs/delta-event-fanpage.git
cd delta-event-fanpage
# 直接双击 index.html 即可
```

如果你更喜欢用本地服务器：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

> 注意：由于部分图片/音乐来自外链或图床，离线且未缓存时可能无法加载；内嵌 SVG 不受影响。

## 部署

本项目为纯静态单文件网页。以热铁盒网页托管为例：

1. 将 `index.html` 上传到网站根目录。
2. 确保外链图片、音乐、图床地址可公开访问。
3. 访问 https://haavkwebsite.rth1.xyz 检查效果。
